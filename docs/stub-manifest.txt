# stub-manifest.txt - the reviewed verdict for every empty function body.
#
# Checked by tools/stub-report.py. An empty function is indistinguishable from
# a finished one at the call site, so each one is looked at once and the answer
# written down here. A new empty function that is not in this file shows up as
# UNCLASSIFIED and the tool exits non-zero.
#
# Format:  VERDICT<tab>path/to/file.c:FunctionName<tab>reason
#
#   BY-DESIGN        empty is the correct implementation
#   UPSTREAM         empty in Quake 3 / ioquake3 / Quake3e too
#   WIRED-ELSEWHERE  the behaviour exists, in the function named in the reason
#   GAP              genuinely missing - these are the ones to fix
